# kimishinu-onigiri-bridge
A high-concurrency, multi-source news-polling microservice and inbound ETL pipeline built with Go, PostgreSQL, and River. Ingests, deduplicates, and normalizes Kimi ga Shinu made Koi o Shitai (KimiShinu) updates from Twitter/X, MangaDex, YouTube, etc... storefronts to deliver real-time automated alerts to the KimiShinu Discord server.
